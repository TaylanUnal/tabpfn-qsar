## TabPFN on the QSAR Biodegradation Dataset

MCBDD Module IV exercise – University of Basel, Spring 2026.

Applying TabPFN (Hollmann et al., Nature 2025) to a small molecular property prediction task. Benchmarked against Random Forest, XGBoost, and Logistic Regression. Dataset: QSAR Biodegradation from OpenML (id 1494).
